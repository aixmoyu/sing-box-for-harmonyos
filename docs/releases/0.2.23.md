# 0.2.23 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。

## 节点导入页实时测速

- 节点列表每行右侧显示当前延迟：`xxx ms`、`超时`、未测到时的 `—`；颜色按延迟分级（<800ms 绿、<1500ms 橙、其余红）。
- 进入“节点导入”页且基础配置正在运行时，自动每 **20 秒**测一轮；右上角新增 **测速** 按钮可立即手动触发。
- 测速使用基础配置里节点对应的 outbound tag（`名称 · id`），逐个串行执行，避免并发把内核命令队列堵住。
- 只在页面可见且应用在前台时测速；离开页面、切到后台或节点发生变化时停止并清空旧结果。
- 基础配置未运行时显示“启动基础配置后自动实时测速”，此时没有内核可用，无法测延迟。
