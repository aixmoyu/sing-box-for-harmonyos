# 0.2.39 WebRTC 严格防护与检测

- 在“应用设置”增加 WebRTC 严格防护：规则／全局模式下优先拒绝已识别的 UDP STUN，不受常规直连分流规则抢先放行。对导入的完整自定义 JSON 同样生效，保留原始配置。
- 保留原来的 STUN 代理方式；严格防护默认关闭，升级不擅自改变用户选择。支持开关持久化、多 TUN 入站和配置原有模式大小写。
- 增加应用内检测页与外部浏览器复测入口，区分 host、srflx 和 relay，分别显示 IPv4／IPv6 HTTPS 出口。浏览器不支持或未得到候选时不宣称安全。
- 直连模式、SSID 挂起和排除应用继续按明确设置直连。严格防护可能影响语音、视频和游戏，不会阻止浏览器经 HTTPS 公开本机候选，也不是系统 Kill Switch。

真机基线：华为浏览器支持 ICE 检测；Google 与 Cloudflare 的 STUN IPv4 与 HTTPS IPv4 相同，且与此前截图的代理 IPv4 相同。三组 host 候选为私网 IPv4。IPv6 HTTPS 检测未成功，未出现 IPv6 候选，因此不能声称已经验证或解决原来的 IPv6 场景。
