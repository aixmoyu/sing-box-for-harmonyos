# 0.2.10 更新说明

非官方 HarmonyOS 移植，sing-box 内核 1.14.3。本版合并挂起恢复与节点、设置保留修复；0.2.9 未单独公开发布。

## 节点和设置保留

- 修复手动选中的节点仅在运行时生效，挂起恢复或重新启动后又回到配置默认节点的问题。用户反馈的慢速现象中，已发现恢复后选回较慢节点的情况；这不等于确认网络优化降低了吞吐。
- 各配置、各策略组分别保存手动节点选择，规则／全局／直连模式也会保存。成功操作后立即写入加密用户存储，启动及挂起恢复时载入，不修改原始配置 JSON。
- 选择记录位于持久用户目录，停止服务和清理临时启动快照不会删除它。覆盖更新时沿用稳定存储名称。
- 仪表盘卡片显隐、策略组折叠、日志筛选和系统应用过滤会保存；原有外观、分应用规则和 SSID 设置继续保留。

## 挂起与网络恢复

- 命中排除 SSID 时停止节点代理服务，销毁系统 VPN／TUN，丢弃旧 VPN 连接对象。挂起期间全部应用不代理。
- 保留 Extension 网络监听及必要心跳，便于离开排除网络后自动恢复。
- 恢复时新建 VPN 连接和 TUN，重新保护进程网络、复验配置、启动新代理服务，恢复之前保存的节点和模式。
- 启动前后检查 SSID 和物理网络；启动过程中再次切网时清理资源，保持挂起等待重试。
- 保留后台暂停界面刷新、自动测速和完整快照的行为，没有限制协程数量。系统可能缓存界面进程，不能理解为只剩 Go 进程运行。

## 安装与验证

使用不带 requires-acl 的普通 HAP，用原签名身份直接覆盖安装并保留应用数据。首次使用本版后重新选择一次节点以建立保存记录；旧版未保存且已丢失的选择无法自动找回。

174 项相关检查通过，包含存储重建后的选择恢复、各配置／策略组隔离、挂起后新服务继续使用手动节点、模式及界面设置保留。普通及 ACL 两种 Release 构建通过，安装包与对应源码已核对。内核二进制与 0.2.8 一致。

这是测试发布，尚未完成本版签名真机跨版本覆盖、吞吐及功耗对比，不承诺性能提升百分比。

两个 HAP 都未签名。requires-acl 包仅供具有获批 GET_BUNDLE_INFO_PRIVILEGED 签名描述文件的用户验证完整应用列表；声明权限或普通签名不会取得系统授权，普通签名安装该包可能失败。

附件包括普通 HAP、ACL 专用 HAP、完整对应源码和 SHA256SUMS。源码不包含个人节点、录屏、应用清单或签名资料。
