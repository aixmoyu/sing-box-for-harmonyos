# 0.2.20 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。基础配置改为按你给的 `两台节点-sing-box.json` 结构生成。

## 基础配置结构

- 结构与参考文件一致：`log`、`dns`（`dns-remote` 走 proxy + `dns-local`，final 为 `dns-remote`）、TUN 入站（IPv4/IPv6 双栈）、`outbounds` 中的 `proxy`（selector，含 `AUTO`、全部节点、`direct`，默认 `AUTO`）与 `AUTO`（urltest），`route.final` 按分流方式决定。
- 参考文件里的两个示例节点不会写进基础配置；只使用你导入的节点。

## 基础配置页：两个二级菜单

- **节点导入**：显示当前节点与订阅数量，点进去就是节点列表。
- **分流方式**：`GFW 分流`（仅 GFW 名单走 proxy，其余直连，final direct）与 `代理大陆以外流量`（大陆域名/IP 直连，其余走 proxy，final proxy），选择后立即重建基础配置；正在运行时自动重启生效。
- 规则集更新与“使用基础配置”保留在本页下方。

## 节点导入的“+”

- 节点页标题右侧新增 **+**，点开是：`手动输入`、`二维码导入（支持订阅）`、`URL 导入（支持订阅）`。
- 二维码和 URL 都会先识别内容：节点链接直接导入；`https` 订阅下载后按订阅导入（可后续更新）；sing-box JSON 会提取其中的 proxy 出站为节点。

## sing-box 格式导入

- 直接粘贴或通过 URL 导入 `两台节点-sing-box.json` 这类配置时，会读取 `outbounds` 里的代理节点（vless / hysteria2 / vmess / ss / trojan / tuic 等），跳过 `selector`、`urltest`、`direct`、`block`。
- 每个节点转成标准分享链接后存进节点目录，因此仍可编辑、分享、参与 proxy/AUTO 分组。

## 其他

- 运行时新增/删除节点、切换分流方式都会走“校验配置 → 重建 → 重启核心与 VPN”，失败自动回连上一份配置。
- 启动成功后仍保留静默更新规则集（每天最多一次）。
