# 0.2.12 更新说明

非官方 HarmonyOS 移植，sing-box 内核升级至官方稳定版 1.14.4。本次测试发布包含此前未公开的 0.2.11 改动。

## 仪表盘模式

- 修复隐私适配同时加入 rule/Rule、global/Global，导致模式重复显示的问题。
- 固定按“直连｜规则｜全局”排列，规则居中；沿用配置的模式大小写，避免仅改显示文字而影响匹配。

## 后台与恢复

- 分别检查系统 VPN 通道与内核状态。连续确认自有 VPN 消失或内核明确停止后，尝试重新建立 TUN 和代理服务；节点测速失败不会触发重启。
- 恢复采用 5／15／60 秒退避，120 秒内最多尝试 3 次；读取失败不视为通道消失，不抢占其他 VPN。
- 保留后台暂停界面刷新、波形和自动测速的资源优化，以及手动停止、SSID 排除和节点选择的优先级。
- 返回前台时保留最后页面状态，并在确认会话失效后通过原有停止确认流程恢复。无法承诺整个 Extension 被系统结束后自动复活。

## IPv6、DNS 和 WebRTC（关联 #1，待真机复测）

- 系统 VPN 接管 IPv4 和 IPv6。“允许 IPv6”关闭后仍捕获 IPv6，再在 TUN 内拒绝，避免因不接管而绕过。
- 新增默认开启的“WebRTC 防直连”：规则／全局模式的 STUN 流量经识别后交给代理出站；节点需要支持 UDP。原始配置 JSON 不被改写。
- 配置有 DNS 服务器时，将捕获入站的 53 端口 DNS 交给内核处理，保留用户 DNS 服务器与规则。
- 直连模式、SSID 挂起及排除应用仍按明确设置直连。不能保证隐藏浏览器的所有本地 host candidate；尚未完成真实 IPv6／STUN／DNS 出口及耗电对比，不能据编译通过宣称泄漏已彻底解决。

## 安装与验证

普通用户下载 `sing-box-HarmonyOS-0.2.12-core-1.14.4-unsigned.hap`，自行签名。覆盖更新请使用原签名身份并保留应用数据。

`requires-acl` 包仅供具有获批 GET_BUNDLE_INFO_PRIVILEGED 签名描述文件的用户；声明权限不代表获得权限，普通签名可能无法安装。

194 项相关 Node 测试通过；原生快照和物理网络选择测试沿用本次 1.14.4 内核的已通过结果；两种 IPv6 隐私配置通过官方 1.14.4 CLI 校验；普通及 ACL Release 构建通过。0.2.11 曾在目标手机观察到 VPN 进程和实际流量，0.2.12 尚未安装真机验证。

附件包含普通 HAP、ACL 专用 HAP、完整对应源码和 SHA256SUMS。未包含个人配置、日志、录屏或签名资料。
