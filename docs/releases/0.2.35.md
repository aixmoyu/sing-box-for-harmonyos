# 0.2.35 导入节点独立测速测试版

- 修复节点页提示“请先启动基础配置”后无法测速的问题。手动测速可在未连接 VPN 或使用自定义配置时运行，不要求切换到基础配置。
- 手动测速使用该节点的实际协议、认证、TLS 和传输参数，执行内核 URLTest；不会以 TCP 握手代替代理连接延迟。
- 临时实例只加载一个代理出站，没有 TUN、监听端口、规则文件、缓存数据库，也不修改当前配置、节点选择或 VPN 状态。连接套接字沿用系统公开接口绑定有效物理网络。
- 测完关闭实例；退出页面、应用进入后台或按需策略挂起时取消临时测速。排除 SSID 生效时不发起新的代理测试。
- 基础配置已运行时，保留原有前台自动刷新；其他情况只在点击“测速”时启动临时测试，避免周期性创建临时实例。
- 保留 0.2.34 的按需响应和网络切换修复。

验证：40 项相关测试、4 项 Go 配置限制和取消测试通过；13 种节点协议生成的临时配置通过官方 sing-box 1.14.4 配置检查。全量 380 项：336 通过、43 项原有失败、1 跳过，无新增失败。Release HAP 构建成功。
