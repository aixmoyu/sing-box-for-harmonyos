# 0.2.15 更新说明

未签名测试发布；内核仍为官方稳定版 sing-box 1.14.4。配置按 sing-box 1.15 的写法生成（已移除 1.15 弃用的 TUN `stack` 选项），界面沿用现有卡片风格。

## 一个基础配置，合并 GFW 与大陆以外分流

- 原来的“大陆以外代理”“GFW 分流”合并为单个内置“基础配置”，不可删除。
- 分流顺序：私有地址直连 → 大陆域名（cn 规则集）直连 → 大陆 IP（geoip-cn）直连 → GFW 名单走代理 → 其余走 `proxy`。
- 分组结构与 Android 版一致：`proxy` 是 selector，成员为 `auto` + 全部导入节点，默认选中 `auto`；`auto` 是 urltest，成员为全部导入节点。
- DNS：`bootstrap-dns`（223.5.5.5，走直连）与 `remote-dns`（1.1.1.1，走代理）；cn 域名用 bootstrap，GFW 与其余用远程。
- 基础配置自带 TUN 入站，包含 `172.19.0.1/30` 与 `fdfe:dcba:9876::1/126` 双栈地址，不再依赖运行时补 IPv6。
- 旧版的两个内置配置会在启动时自动合并迁移，选中的旧配置会转移到新的“基础配置”。

## IPv6 改为跟随配置

- 设置里的 IPv6 开关改为只读状态：配置包含 IPv6（TUN 地址、DNS 或节点地址）时自动开启并走代理，否则在 VPN 内拒绝 IPv6，DNS 使用 `ipv4_only`。
- “基础配置”带 IPv6 入站，因此默认开启；用户自带 IPv4-only 配置会自动关闭，不需要手动切换。

## 仪表盘与列表

- 仪表盘配置选择（弹层）增加与配置页一致的操作：右滑编辑（蓝）、左滑删除（红）、长按多选、全选、批量删除。
- 选定“基础配置”但尚未导入节点时，仪表盘配置卡片下用红字提示“尚未导入节点：请到 工具 → 导入节点 添加，或导入你自己的配置”。
- 工具页第二个二级菜单改为“基础配置”，进入后可确认或切换为内置基础配置。

## 验证范围

- 100 项相关 Node 检查通过，覆盖单基础配置的分流顺序、proxy/auto 结构、IPv6 自动判定与旧配置迁移。
- 官方 1.14.4 CLI 校验基础配置与其运行配置（含 TUN 适配）通过。
- Release HAP 构建通过；**尚未安装真机验证**，分组显示、滑动手势和 IPv6 自动开关需要真机确认。

## 限制

- 只支持复制／系统分享节点链接，暂不生成二维码图片。
- 1.15 的 TUN 栈改进需要内核升级才生效；当前 1.14.4 会使用其默认栈。
