# 0.2.14 更新说明

未签名测试发布；内核仍为官方稳定版 sing-box 1.14.4，原生部分未改动。界面沿用现有卡片风格，只补交互和入口。

## 内置基础配置：proxy / auto 两组

- “大陆以外代理”和“GFW 分流”两套内置配置，按 Android 版的分组结构生成：`proxy` 组包含 `auto` 和全部已导入节点；`auto` 是 `urltest` 组，同样包含全部节点，按延迟自动选择。
- `proxy` 默认选中 `auto`，所以导入节点后直接启动即可，不需要先手选节点；在代理组里切到具体节点时，选择会按配置保存。
- 两套配置都内置 DNS（阿里 DoH 引导 + Cloudflare 远程）、cn / geoip-cn / gfw 规则集与 TUN 适配，不需要手写 JSON；内置配置不可删除。

## 工具页：两个二级菜单

- **导入节点**：一个页面里提供链接导入、二维码、手动添加三条入口；下方是节点列表和订阅列表（更新、删除）。
- **内置基础配置**：选择“大陆以外代理”或“GFW 分流”，点一下即切换为当前配置并返回。

## 列表交互（节点与配置一致）

- 列表按现有卡片样式排列（同样的圆角、底色、字号）。
- **右滑显示“编辑”（蓝色），左滑显示“删除”（红色）**；内置配置的“编辑”跳到节点页，删除会提示不可删除。
- **长按进入多选**，顶部出现“已选 N / 全选 / 删除 / 取消”；节点多选另外提供分享（复制链接）。
- 配置卡片仍保留远程配置的“更新”和内置配置的“节点”快捷按钮。

## 沿用 0.2.13

- IPv6 默认关闭；关闭时 VPN 仍接管 IPv4/IPv6 与 `::/0`，IPv6 在 TUN 内拒绝，配置有 DNS 时用 `ipv4_only`，AAAA 返回空答案。
- 启动日志新增 `IPv6 策略:` 行。

## 验证范围

- 100 项相关 Node 检查通过，包含 6 项开箱即用检查（节点导入、proxy/auto 结构、TUN 适配、内置配置同步与不可删除、自定义配置保留）。
- 官方 1.14.4 CLI 校验“大陆以外代理”“GFW 分流”两份运行配置通过。
- Release HAP 构建通过；**尚未安装真机验证**，滑动手势、长按多选和内置配置实际启动仍需真机确认。

## 限制

- 只支持复制／系统分享节点链接，暂不生成二维码图片；二维码仅支持扫码导入。
- 内置配置的规则集来自打包的 .srs 文件，升级内核时需要同步重新生成。
