# 0.2.34 本地网络切换修复测试版

- 文件监听失败时，SSID 策略改用现有心跳兜底检查：前台约 1 秒、后台约 3 秒，不再因网络事件监听可用而等待 30 秒。
- 网络变化或排除 SSID 生效时，取消当前原生节点测速，再按顺序停止、重建服务。保留核心互斥锁，防止测速访问已经销毁的出站。
- 网络验证短暂消失时保留上一个有效网络，恢复后仍可识别 Wi-Fi／蜂窝切换；网络类型由系统能力确定。
- 正常跨网络重建使用独立、有上限的重试预算，成功后清零，不消耗核心故障恢复预算。
- 排除 SSID 优先于恢复重试等待；继续保留手动停止、其他 VPN 保护、节点与模式持久化以及后台低频采样。

验证：56 项相关测试、3 项原生测速取消测试通过，Release HAP 构建成功。全量 364 项：320 通过、43 项原有失败、1 跳过；没有新增失败。修正了一个既有测试桩缺少 hilog 的问题。

无线调试检查的是手机已安装的 0.2.33。临时添加的当前 Wi-Fi 排除项已删除，已确认原列表为空、VPN 恢复已启动。未精确测出原版挂起时延，未安装或真机验证 0.2.34；上述 1／3 秒是调度检查周期，不能承诺系统网络验证及 VPN 创建也在该时间内完成。IPv6／WebRTC 自定义配置问题仍待进一步区分浏览器候选地址与实际直连出口，本版不宣称已解决泄漏。
