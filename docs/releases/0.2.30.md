# 0.2.30 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。

## 升级安装后自动重建 VPN

- 覆盖安装会把正在运行的 VPN 扩展进程替换掉，系统里的 VPN 失去心跳，界面就会显示“VPN 扩展心跳已中断”，此时旧会话既不能用也不会自动恢复。
- 现在应用启动时会比较当前版本与本机记录的版本：
  - 检测到版本变化（升级）且升级前 VPN 处于运行状态，或当前状态已经是“心跳已中断”，就会先安全停止残留会话，再用当前选中的配置重新建立 VPN/TUN，并提示“VPN 已重新建立”。
  - 首次安装（没有历史版本）不会自动启动 VPN；升级前本来就是停止状态的也不会被自动拉起。
- 运行状态会持久化成“用户意图”（`vpn-active`），所以即使升级时扩展进程被杀，重新打开应用也能判断升级前是否在运行。

## 行为说明

- 触发时机是升级后第一次打开应用，约 1.5 秒后开始重建（等首轮状态读取完成）。
- 重建使用当前选中的配置与分应用/分流设置，节点选择仍然沿用已保存的记录。

## 验证范围

- 103 项相关 Node 检查通过。
- Release HAP 构建通过；**尚未安装真机验证**，升级后的自动重建需要你实际覆盖安装一次确认。

## 提示

- 如果升级后没有自动重建，先看是否升级前 VPN 处于停止/挂起状态；也可以在设置里手动启动一次，之后升级就会自动恢复。
