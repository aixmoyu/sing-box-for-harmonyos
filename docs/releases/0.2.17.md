# 0.2.17 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。

## 基础配置可更新规则集

- “基础配置”页新增 **更新规则集（GFW / 国内域名）**：从 sing-geosite / sing-geoip 下载 `cn.srs`、`geoip-cn.srs`、`gfw.srs`。
- 三个文件先写入临时文件，校验 `SRS` 头和长度，全部成功后才替换；任一失败保留原规则并在弹窗里给出原因。
- 应用启动时不再用安装包内置规则覆盖已更新的文件（只补齐缺失文件），所以更新后的 GFW / 国内域名规则会保留。
- 更新完成后如果基础配置正在运行，会自动重启核心与 VPN 让新规则生效；页面显示上次更新时间。

## 运行时添加节点会自动生效

- 不再要求“先停止内置配置再改节点”。运行中添加、导入、编辑或删除节点后：
  1. 重新生成基础配置（proxy / auto 两组同步包含新节点）；
  2. 重新解析并适配配置（节点不合法就不会进入内核）；
  3. 自动重启核心与 VPN，然后提示“节点已更新，核心与 VPN 已重启”。
- 删除到 0 个节点时，自动停止代理并提示先导入节点。
- 重启失败会保留已保存的节点并提示手动重连，不会静默继续用旧配置。

## 验证范围

- 100 项相关 Node 检查通过（100 项执行）。
- Release HAP 构建通过；**尚未安装真机验证**，规则集下载、热重启与节点即时生效需要真机确认。

## 限制

- 规则集来源是 GitHub raw，网络受限时更新会失败，旧规则继续使用。
