# 0.2.33 本地测试版

基于 0.2.32 修复本次审查确认的七类问题；内核保持 sing-box 1.14.4，不引入备用的 1.15 测试内核。

- 节点库与解析器共用 URI/订阅识别，新增协议不再误当作 Base64；保留原始分享链接，保持已有节点 ID 和存储格式。
- 修复 SOCKS/HTTP 手动表单丢密码、TUIC 表单回填丢密码的问题。
- 规则更新改用 MetaCubeX/meta-rules-dat 的三个真实文件地址，与随包规则来源一致；并发的手动/自动更新共用一次下载，下载失败保留原规则并清理候选文件。
- 修复初始化时保留规则的判断被写进注释，避免覆盖运行时已更新的规则。
- JSON 节点提取会检查未建模字段和分享链接回读结果。HY2 混淆等无法完整转换的参数将明确报错，并提供“作为完整配置导入”，不再默默删参数后保存坏节点。该改动不声称新增了 HY2 obfs 分享链接支持。
- 节点测速增加任务代次和在途请求保护，后台/离页后的旧任务不再发布结果，也不会与返回页面后的新轮次重叠。

本版不改手机节点、订阅、节点选择的存储结构，不清空已有数据；覆盖安装仍须保持原签名身份、保留应用数据。

验证：新增 23 项回归测试通过，73 项相关检查全部通过；全量现有测试 358 项，其中 313 通过、44 失败、1 跳过。44 项失败与修复前相同，涉及环境、旧锁/旧断言等，未宣称全量通过。规则集三个新地址均已实际下载验证，两种基础配置及下载规则通过官方 1.14.4 CLI 校验；Release HAP 构建通过。

尚未在手机安装本修复版或完成真实代理、后台待机、IPv6/STUN 与手势验收。尚未上传 GitHub。

修复前 0.2.32 的应用源码和原 HAP 已保存。本次另提供包含前后 Git 标签的本地 bundle、正向/回退补丁及 SHA-256 清单。回退补丁仅还原此次源码修改，不恢复或删除手机里的节点数据。
