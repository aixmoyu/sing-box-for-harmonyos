# 0.80 更新说明

发布日期：2026-10-25。应用版本由 0.2.40 升至 0.80，数据格式与加密标识保持兼容。

- 修复独立节点测速未初始化界面进程 libbox 的问题。基础配置运行时优先复用已加载节点；未启动 VPN、运行自定义配置或按需挂起时，手动测速使用临时无入站实例，不切换配置、不恢复 VPN。
- 独立测速使用已验证 Wi-Fi／蜂窝物理网络的 DNS，并保留逐 socket 物理网络绑定，避免固定公共 UDP DNS 不可达，以及自定义 VPN 的 FakeIP／DNS 规则干扰。
- “基础配置”改为向下展开菜单，包含“节点选择”和“模式选择”。工具页的 WebRTC 检测放在基础配置之后。
- “WebRTC 防护”独立于主题设置，增加明确的“禁用 STUN”开关（沿用原严格防护设置，不重置旧选择）。禁用 STUN 可独立开启；规则／全局模式拒绝可识别的 UDP STUN。
- 增加 GitHub 更新提示：前台启动后每天检查一次，设置中可手动检查。仅提示同一内核渠道，打开 Release 页面下载；需要原签名覆盖安装。
- 关于页显示实际应用版本、内核版本与渠道；保留原配置、节点、节点选择及设置。

## 安装包与渠道

稳定版：应用 0.80，sing-box 1.14.4（上游正式版）。Beta：应用 0.80-beta，sing-box 1.15.0-alpha.13（上游预发布版）。稳定／Beta 按内核区分，不按应用版本号或测试完成度命名。两个应用包名不同，不能跨渠道覆盖共享数据。

HAP 为未签名包，请沿用各自原签名覆盖安装。不要卸载或清除数据。

## 验证与已知限制

本次相关 39 项测试通过；13 种生成的测速配置通过官方 1.14.4 配置检查。全量测试中有 45 项与修改前相同的历史失败，主要涉及构建输入锁和既有工程约束，并非全量通过。0.80 新包尚未完成用户签名后的真机三状态测速回归。

0.2.40 已在真机验证旧 Beta 配置恢复及 VPN 启动。此前自定义配置 Wi-Fi 下的 STUN 开／关／开对照结果只证明 UDP STUN 拦截能生效。原截图的运营商 IPv6 暴露仍未判定解决；本版不作“WebRTC 零泄漏”承诺。直连模式、SSID 挂起和排除应用保留直连语义。
