# 0.2.16 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。本次按参考视频补手动导入流程，并锁定内置基础配置。

## 手动导入：按协议添加

- “手动添加”改为参考视频的菜单：`添加 [VMess]`、`添加 [VLESS]`、`添加 [Shadowsocks]`、`添加 [Trojan]`、`添加 [Hysteria2]`，选中后直接进入对应协议的表单。
- 表单字段按 v2rayNG 的命名：别名（remarks）、地址（address）、端口（port）、用户 ID（id）或密码（password）、加密方式（security / method）、传输协议（network）、TLS（security）。
- VMess 增加“加密方式（security）”和 `alterId`；Shadowsocks 保留 method；VLESS 保留 flow；ws / grpc / http 才显示 path 与 host。
- 仍可切换“直接编辑分享链接”，保留协议扩展参数；保存后回到节点列表。

## 基础配置不可删除

- 基础配置在配置列表和仪表盘选择器里左滑只显示灰色“内置”，不再出现删除按钮。
- 删除入口（单项删除、批量删除）对内置配置一律拒绝，底层 `deleteSfaProfile` 也会抛错，避免误删。
- 其余（代理组 proxy/auto、IPv6 随配置自动开关、红字提醒）沿用 0.2.15。
