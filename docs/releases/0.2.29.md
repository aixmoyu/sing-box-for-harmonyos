# 0.2.29 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。

## proxy 组移除 direct

- 基础配置的 `proxy`（selector）成员改为 `AUTO` + 全部已导入节点，不再包含 `direct`。
- `direct` 出站仍然保留，供直连规则使用，只是不再出现在代理组的可选列表里。
- 已在 1.14.4 CLI 校验两种分流方式的配置依然通过。

## 影响

- 在代理组里切换节点时，不会误选“direct”导致看起来连上了但实际直连。
- 需要直连时用“直连”模式或规则里的 direct，不会影响基础配置的代理逻辑。

- 103 项相关 Node 检查通过（含 proxy 不再含 direct 的断言）。
