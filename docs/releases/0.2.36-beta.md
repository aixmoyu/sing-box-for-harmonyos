# 0.2.36-beta（1.15.0-alpha.13 备用内核 · 共存测试包）

未签名测试发布。基于 0.2.35 源码，仅替换内核与包名，用于和稳定版同时安装对比。

## 包信息

- 包名：`com.harmonynet.assistant.beta`（稳定版是 `com.harmonynet.assistant`），两个应用可以同时安装。
- 名称：sing-box 测试版。
- 版本：0.2.36-beta（versionCode 1000040）。
- 内核：sing-box `1.15.0-alpha.13`（官方测试版，提交 824dbcfb），来自此前编好的备用共享库；稳定版内核 1.14.4 已备份在 `work/core-backup-1.14.4-20261025`。

## 为换核做的适配

- 备用内核早于 0.2.35，**没有** `HnaCoreTestConfig` 桥接导出。桥接层把它声明为弱符号并加空指针判断，内核缺这个符号时库仍能正常加载，临时测速会返回“不支持”，其余功能不受影响。
- VPN 扩展的启动/停止 Want 改成运行时读取本包 bundleName，否则改了包名会启动不了自己的 VPN 扩展。
- 其余源码与 0.2.35 一致（导入节点独立测速、按需连接、网络切换修复等）。

## 已知差异与限制

- 0.2.35 新增的“未运行 VPN 时用临时实例测节点延迟”在这个包里不可用（备用内核没有该入口）；基础配置运行中的实时测速不受影响。
- 1.15 是 alpha 内核：配置在 1.15 有变更（例如 TUN `stack` 已标记弃用），应用仍会按现有配置生成；实际兼容性未在手机验证。
- 测试版是独立应用，数据目录独立，不会继承稳定版的配置和节点。
- 未上传 GitHub、未签名、未真机验证。

## 恢复稳定版构建

需要重新构建稳定包时，把 `work/core-backup-1.14.4-20261025` 里的 `libharmonycore.so` / `.h` 复制回 `work/HarmonyNet/core/go/out/`，并把 `AppScope/app.json5` 的 bundleName、版本号、label 改回稳定版即可（本次打包后工作区已自动恢复为稳定版配置）。
