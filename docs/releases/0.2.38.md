# 0.2.38 节点测速修复

- 修复临时测速启用自动接口选择、但鸿蒙适配未提供接口列表导致连接失败的路径。改用已经适配的公开接口逐套接字绑定物理网络；原生入口拒绝再次传入自动接口选择配置。
- 修复 Beta 0.2.36 的原生接口不匹配：界面库引用 HnaCoreTestConfig，旧 alpha 内核却没有导出它。稳定内核和1.15.0-alpha.13现分别重新编译同版桥接，逐项检查引用与导出。
- 允许按需连接处于 SSID 挂起状态时手动测速。临时实例没有 TUN，不恢复 VPN，不改变挂起标志；自动测速仍暂停，离开节点页或退到后台取消测试。
- 修复所有失败都显示“超时”的问题。初始化、DNS、TLS、连接、握手和超时分别显示固定中文分类；不会把节点地址、密码或原始错误写入界面或日志。
- 保留工作区已有0.2.37 DNS防护等改动，并补齐英文Beta名称资源。0.2.35及以前回退检查点保留。

验证：43项测速相关测试、4项纯Go配置/取消测试通过；13种协议配置通过官方1.14.4 CLI检查；两个内核和Release HAP构建、包内ABI匹配检查通过。全量测试仍有历史失败，详细数量见构建记录，不宣称全绿。

尚未签名安装0.2.38验证真实节点延迟。无线调试取得的应用记录包含Beta通道；系统拒绝执行未签名的独立诊断程序，因此没有绕过执行限制。临时测试修复不能作为IPv6/WebRTC已解决的证明。未上传GitHub。
