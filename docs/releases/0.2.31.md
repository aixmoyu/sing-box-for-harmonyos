# 0.2.31 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。

## 节点导入页：Clash 风格测速按钮

- 节点页标题右侧新增带闪电图标的 **测速** 按钮：点一下依次测全部已导入节点，按钮内实时显示进度（如 `3/10`），每行右侧同步刷新 `xxxms` / `超时`。
- 测速仍然串行执行，避免同时压内核命令队列；离开页面或切到后台会停止。
- 进入页面时的自动测速保留（每 20 秒一轮），手动按钮用于立即刷新。

## 修正

- 测速使用的 outbound tag 改为与基础配置完全一致（`节点名称 · id`）。之前名称异常的节点会拼错 tag，表现为一直“超时”。
- 未启动基础配置或当前选中的不是基础配置时，点测速会提示“请先启动基础配置，测速需要内核运行”，不再无反应。
