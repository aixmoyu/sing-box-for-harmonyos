# 0.2.13 更新说明

未签名测试发布；内核仍为官方稳定版 sing-box 1.14.4（未改动原生部分）。

## IPv6 默认关闭

- “允许 IPv6”改为默认关闭；从旧版升级时，旧设置里继承的“开启”会迁移一次为关闭。需要 IPv6 时可在“设置 → 外观”重新打开，之后的明确选择会被保留。
- “关闭”是在内核侧拒绝 IPv6，不是不接管 IPv6：系统 VPN 始终配置 IPv4 / IPv6 地址，并同时安装 `0.0.0.0/0` 与 `::/0` 默认路由；IPv6 数据包会进入 TUN，再按拒绝规则丢弃，不会从物理网络绕过。
- 关闭且配置包含 DNS 服务器时，同时把 DNS 策略设为 `ipv4_only`；内核收到 AAAA 查询直接返回空答案，避免应用和 STUN 继续解析 IPv6 目标。DoH/DoT 或缓存里的 AAAA 仍由上述拒绝规则拦截。

## 判断“WebRTC IPv6 泄露”

- 显示 `fdfe:dcba:9876::/126` 或 `fe80:` 开头：这是 VPN 隧道自身接口地址（浏览器 host candidate），不是公网地址泄露；本实现无法替浏览器隐藏本地接口地址。
- 显示 `240e:`、`2408:` 等运营商公网 IPv6：说明 IPv6 实际绕过了隧道，需要继续排查；关闭 IPv6 后若仍出现，即为此类问题。
- 显示节点服务器的 IPv6：说明 IPv6 已按配置走代理，不是泄露。
- 已知直连路径：直连模式、SSID 挂起、分应用代理排除的应用，以及 STUN 直连的语音，都会按明确设置直连。

## 诊断

- VPN 启动日志新增 `IPv6 策略: …` 一行，可直接确认本次运行是“关闭（拒绝）”还是“代理双栈”。
- 本次只调整默认值与 DNS 策略，未改动 TUN 创建、路由安装和拒绝规则的核心逻辑。
