# 0.2.32 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。

## 按需连接改成节点列表的 UI 模式

- 顶部标题行 + 右侧 **+** 添加 SSID，显示已添加数量与当前连接的 SSID。
- 每个 SSID 一张玻璃卡片（与其他页面一致的毛玻璃材质）：
  - **右滑显示“编辑”（蓝）**，可改名；
  - **左滑显示“删除”（红）**；
  - 点卡片直接进入编辑；**长按进入多选**，顶部出现 `已选 N / 全选 / 删除 / 取消`。
- 空状态改成卡片提示，带“添加 SSID”按钮。
- 编辑框标题会区分“添加 SSID / 编辑 SSID”，提交时替换原条目而不是新增一条。

## 行为保持不变

- 连接排除的 Wi-Fi 时挂起代理，离开后恢复；状态提示仍在列表底部显示。
- 保存后约 5 秒内生效。
