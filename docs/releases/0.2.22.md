# 0.2.22 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。本版回滚了 0.2.20/0.2.21 中导致“节点不测速、自定义配置不可用”的改动。

## 问题原因

1. **去掉了强制 `auto_detect_interface: false`**。鸿蒙端原生层自己做 socket protect 和物理网卡绑定；再让 sing-box 自动探测网卡会选错接口，导致所有出站连接（包括节点测速）失败，自定义配置同样受影响。
2. **去掉了注入 TUN 的 `stack: gvisor`**。1.14.4 在鸿蒙 VPN fd 下需要 gvisor 栈，使用默认栈会连不通。1.15 的新栈要等内核升级后再切。
3. **切网后强制 URLTest**。该操作会持有内核互斥锁最长约 15 秒，网络差时会把后续的测速、停止、重启命令一起堵住。

## 本次修复

- 恢复 `route.auto_detect_interface = false`（对所有配置生效）。
- 恢复注入 TUN 的 `stack: 'gvisor'`；基础配置里保存的 TUN 仍按参考文件写 `auto_route/strict_route`，不写 stack。
- 移除切网后的强制 URLTest；`AUTO` 组仍保持 1 分钟周期重新测速，切网恢复比 0.2.20 快，又不会堵内核。
- 保留：DNS 按分流拆分（大陆走 dns-local、GFW 走 dns-remote）、基础配置页两个二级菜单、sing-box JSON 导入节点、规则集静默更新等。

- 官方 1.14.4 CLI 校验两种分流方式的运行配置通过。
