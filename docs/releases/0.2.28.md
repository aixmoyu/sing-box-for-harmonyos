# 0.2.28 更新说明

未签名测试发布；内核仍为 sing-box 1.14.4。按参考视频重做界面材质与对比度。

## 毛玻璃材质（参考“置顶消息 / 输入框”）

- 所有页面底层换成彩色渐变壁纸（浅色为青绿→淡蓝，深色为深蓝→深紫），毛玻璃才有可模糊的内容。
- 仪表盘、配置、节点导入、基础配置、设置、日志等页面的卡片统一改为：半透明玻璃底 + 背景模糊（radius 18、saturation 1.25）+ 0.8vp 高光细边，接近参考视频里置顶消息条和输入框的质感。
- 顶部标题栏、底部导航、运行状态栏原有的模糊保留并与新材质统一。
- 设置里的“减少透明效果”仍然有效：打开后关闭所有模糊、改用不透明底色，低性能设备可用。

## 对比度

- 浅色主题：正文 `#0E0E12`、次要文字 `#33353D`，边框与强调色加深，玻璃底提高到 78% 白，保证彩色背景上依然清晰。
- 深色主题：正文纯白、次要文字 `#CFDBE9`，边框 `#2E4A66` / `#43688F`，玻璃底 68% 透明。
- 危险色、警告色、强调色同步提高饱和度对比。
